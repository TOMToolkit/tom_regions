{% comment %} tom_regions/partials/aladin_region_skymap.html Initial-render Aladin Lite v3 viewer with one MOC overlay per region. Two things to understand here. 1. The mocpy <-> Aladin contract. Each region's geometry is fetched from the URL stored in regions[i].moc_url (the regions:moc-json endpoint). That endpoint returns the standard IVOA Multi-Order Coverage JSON shape: {"": [, ...], ...}. mocpy emits this via MOC.serialize(format='json'); Aladin Lite v3 consumes it via A.MOCFromURL(...). Both libraries are first-class consumers of the same IVOA standard, so the wire format is stable -- no custom encoder lives in this codebase. 2. The OOB (Out-of-Band) update pattern.
