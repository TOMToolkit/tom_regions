{% comment %} tom_regions/partials/aladin_region_skymap_oob.html Out-of-band (OOB) script block re-running the Aladin overlay loader against a new region set. Two callers: - The list view's filter HTMX response. ``remove_name`` is empty in that path; the script just refreshes the overlay set. - RegionSaveFromAladinView's success response. ``remove_name`` is the pre-save Aladin overlay name (e.g. "cone"); the script removes that overlay before applying the new region set, so the saved version re-appears under the user's chosen name without leaving a duplicate behind.
